Setup
-----
1. Extract this ZIP.
2. Open PowerShell in the extracted project root.
3. Server:
   cd server
   npm install
   copy .env.example .env
   Edit .env and set MONGODB_URI and JWT_ACCESS_SECRET.
   npm run dev
4. Optional seed data (new terminal, server folder):
   npm run seed
5. Client (new terminal, project root):
   cd client
   npm install
   copy .env.example .env
   npm run dev
6. Open http://localhost:5173

Important
---------
- Do NOT run npm audit fix before the project is tested; dependency upgrades can change behavior.
- node_modules and dist are intentionally not included.
- .env files containing real secrets are intentionally not included.
